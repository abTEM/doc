# Article notebooks

Simulation code accompanying publications that used *ab*TEM. These notebooks originally
lived in the [main *ab*TEM repository](https://github.com/abTEM/abTEM) under `articles/`
and were moved here so that all documentation-like material sits in one place.

> [!WARNING]
> These are historical artefacts, preserved as published. They were written against the
> *ab*TEM 1.0.0beta API of 2021 (`abtem.structures`, `abtem.temperature`, `Measurement`,
> `probe.scan(...)`, and so on) and will **not** run with current *ab*TEM. They are not
> executed, tested or updated by the documentation build, and are deliberately kept as
> they were at the time of publication rather than ported forward.

For working, maintained examples of the same techniques with the current API, see the
[walkthrough](https://abtem.github.io/doc/user_guide/walkthrough/walkthrough.html) and the
[example gallery](https://abtem.github.io/doc/user_guide/examples/examples.html).

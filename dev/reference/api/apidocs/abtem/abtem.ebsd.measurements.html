class abtem.ebsd.measurements.EBSDPatternImages(...)[source]#

Bases: abtem.measurements.Images

A pattern projected onto an EBSD detector.

Like Images, with the detector pixels in micrometres as base axes: x across the detector’s columns and y up its rows, as scintillator_coordinates(). A detector of shape (rows, columns) therefore gives images of shape (columns, rows), which show as the detector sees them. detector_array lays them out as EMsoft and kikuchipy store patterns.

class abtem.ebsd.measurements.SphericalPattern(...)[source]#

Bases: abtem.core.utils.CopyMixin, abtem.core.utils.EqualityMixin

Backscattered intensity sampled at directions on the unit sphere.

Use interpolate() or bin() for a square image of it, and project() for a detector.

A pattern may cover the northern hemisphere, the southern one, or both (hemisphere). For the hemisphere it does not cover, it uses the inversion image of the one it does, I(-k) = I(k), and warns if its metadata records that the crystal is not centrosymmetric.

It is not an ArrayObject, since its base axis is a list of direction vectors.

Parameters:

  • array (np.ndarray) – Intensities of shape (..., N), where the last axis runs over the directions and any leading axes are ensemble axes.

  • directions (np.ndarray) – Unit vectors of shape (N, 3) in the crystal frame.

  • ensemble_axes_metadata (list of AxisMetadata, optional) – Metadata for the leading axes of array.

  • metadata (dict, optional) – Measurement metadata.

interpolate(...) → ReferencePatternImages[source]#

Evaluate the intensities at the nodes of a square grid.

Unlike bin(), it is defined for any grid size. If the pattern was calculated on the same grid, the values are exact.

Parameters:

  • gpts (int) – Number of grid nodes along each axis, spanning [-1, 1].

  • projection (str or HemisphereProjection, optional) – 'lambert' (default) or 'stereographic'.

  • hemisphere ({'north', 'south'}, optional) – Which hemisphere to lay out (default ‘north’). As in EMsoft, the southern node at (X, Y) is the direction (x, y, -z) of the northern one.

Returns:

images – Nodes outside the projection’s domain are zero.

Return type:

interpolate_directions(...) → ndarray[source]#

Evaluate the pattern at arbitrary directions.

Interpolates in the square Lambert plane. A pattern sampled on a Lambert grid, the default of EBSDReferencePattern, is interpolated bilinearly as EMsoft interpolates a master pattern; any other sampling is triangulated and interpolated linearly.

directions (np.ndarray) – Unit vectors of shape (M, 3), anywhere on the sphere. Each is evaluated in its own hemisphere (see southern).

project(...) → EBSDPatternImages[source]#

Project the pattern onto an EBSD detector.

Evaluates the pattern at the direction each pixel looks along, rotated into the crystal frame. The values are a modulation about one, without the Monte Carlo background. With poisson_noise(), total_dose is then the counts per pixel of a featureless specimen.

Parameters:

  • geometry (EBSDGeometry) – The detector geometry.

  • euler (np.ndarray, optional) – Bunge Euler angles of the crystal, of shape (3,) or (N, 3) for several orientations at once (default no rotation).

  • degrees (bool, optional) – If True (default), euler is in degrees.

Returns:

images – Of shape (columns, rows) of geometry.shape (see EBSDPatternImages), with leading axes for any orientations and for this pattern’s own ensemble.

Return type:

EBSDPatternImages

to_emsoft(...) → None[source]#

Write the pattern as an EMsoft EBSD master pattern file.

EMsoft and kikuchipy read the file. Writing it requires h5py, and spglib unless space_group is given.

Parameters:

  • path (str) – Destination .h5 file.

  • atoms (ase.Atoms) – The unit cell the pattern was calculated from, for the crystal data a reader needs to build a phase.

  • npx (int, optional) – Half-width of the square Lambert grid; the stored arrays are 2 * npx + 1 on a side. Defaults to the pattern’s own Lambert grid, whose values are then written as calculated when it has an odd number of points per side, as a reference pattern’s has by default.

  • energy (float, optional) – Beam energy [eV], recorded as the Monte Carlo EkeV. Defaults to metadata["energy"]. The master pattern’s energy bin, EkeVs, is its backscattered electrons’ energy, metadata["backscatter_energy"] (their mean, for a pattern averaged over energies), or the beam energy if it has none.

  • space_group (int, optional) – Space group number. Determined with spglib if not given.

  • sample_tilt (float, optional) – Sample tilt [degrees] recorded in the file (default 70.0).

  • debye_waller (float or sequence of float, optional) – Debye-Waller factor per atom [nm²] (default 0.005, i.e. 0.5 Å²), recorded in the file. It does not change the pattern.

  • name (str, optional) – Phase name recorded in the file.

  • overwrite (bool, optional) – If True, replace an existing file.

Notes

For a pattern of the northern hemisphere alone, the southern one is its inversion image, which is only right for a centrosymmetric crystal; build the pattern with hemisphere='both' otherwise.
